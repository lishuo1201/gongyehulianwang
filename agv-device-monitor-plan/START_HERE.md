# 从这里开始：把计划交给 Codex

版本：1.3｜更新日期：2026-09-14｜语言：中文

本项目面向已有 **7 年 Java 互联网开发经验**、希望补足工业领域知识并应聘工业软件 Java 后端岗位的开发者。学习覆盖完整工业协作链路，工程保持 AGV 模拟设备只读采集监控；实际功能进度以任务交接为准。你负责设计、推理和回答，Codex 负责编码及运行测试，亲手编码为可选练习。每天 2～4 小时、五天 MVP 与十天完善仅作工程预算。

先按 [任务交接](docs/06-tasks.md)核对工程阶段；全部代码与验收完成后，再读 [工业系统全景与产线补料案例](docs/02-architecture.md)，按 [开发与学习计划](docs/05-development-plan.md)恢复集中复盘。Java基础按需复习，陌生工业概念先讲背景再做场景判断；[面试训练](docs/09-interview-guide.md)准备讲述，T20汇总独立回答。

## 当前执行方式

## 1. 如何放进项目

1. 解压文件包。可以直接把 `agv-device-monitor-plan` 文件夹重命名为 `agv-device-monitor`，作为一个新项目。
2. 如果已有项目，把本包内容合并到项目根目录。已有 `AGENTS.md`、`README.md` 或同名文档时先比对，不能直接覆盖。
3. 在这个项目目录打开 Codex，把下面的首次任务发给它。
4. 先查看工程结果；完成所有代码及验证后，再按学习记录逐题复盘。

应用位于`agv-device-monitor-plan/`，包含`backend/`、`simulator/`、Maven Wrapper、Compose和验收脚本；贡献指南位于上级`AGENTS.md`。实际进度以`docs/06-tasks.md`为准。

## 5. 你需要知道的默认选择

- Java 17；Spring Boot 单体后端；MySQL；真实 Modbus TCP 读寄存器。
- 一个独立 Java 模拟器进程，模拟 3 台 AGV；不是 3 个业务微服务。
- 简单 HTML/CSS/JavaScript 页面，后端通过 SSE 单向推送；第一版不引入 Vue 构建链。
- 第一版只监控，不控制真实设备，不实现搬运任务下发、路径规划或完整 MES/WMS。
- 已有真实Modbus/MySQL、HTTP/SSE、浏览器及Compose证据；各项范围和长时测试结果见验收记录，不据此声称生产性能。
- 先完整工程、后集中学习：提问时等待回答，按实际理解与证据决定学习是否通过。

如果你想换成已有 Spring Boot 项目、Python 模拟器或 Vue 页面，先让 Codex记录影响并同步文档，不要只改其中一个文件。
