### T02 数据库迁移与约束

- 读取：数据模型、部署计划。
- 实现：Flyway 或经记录确认的等价增量迁移；5 张表、索引、唯一和范围约束；demo 种子初始化器。
- 验证：真实 MySQL 新库迁移、第二次启动幂等、编码/连接重复被拒、多个历史告警与单活动槽约束。
- 交付：迁移文件、数据库测试、测试隔离说明。
- 验收：空库和已有同版本库均正常；测试不修改个人已有数据库。

### T03 寄存器解码与协议契约测试

- 读取：寄存器表。
- 实现：DeviceSample、RunState、8 寄存器编解码；边界与非法值处理。
- 验证：固定字节样例、unsigned 65535、速度 1200→1.2、心跳环绕、未知协议版本、故障状态不一致。
- 交付：不依赖网络和 Spring 的协议单测。
- 验收：固定样例全部通过，不能仅依赖编码器/解码器互相往返自证正确。

### T04 三设备 Modbus 模拟器

- 读取：架构、接口、寄存器表。
- 实现：端口 1502、Unit ID 1/2/3、整块原子更新、每秒 heartbeat、6 种场景、8081 管理接口。
- 验证：用协议客户端读取真实 TCP；切换 LOW_BATTERY/FAULT/SILENT/FROZEN/INVALID；单 unit 故障不影响其他 unit。
- 交付：simulator 源码、场景测试与启动方式。
- 验收：真实网络返回与固定寄存器表一致；跨界地址和未支持写功能明确拒绝。

### T05 Java 真实协议读取适配器

- 读取：寄存器表、架构采集流程、选定库当前版本文档。
- 实现：DeviceClient 接口与 ModbusTcpDeviceClient；连接复用/释放、异常分类、时间预算。
- 验证：连接模拟器解码 3 台；拒绝连接、无响应、异常响应、晚到响应；实际执行时间有上界。
- 交付：适配器与 TCP 集成测试，超时参数的实测说明。
- 验收：服务端 SILENT 不永久占线程，close 后资源释放；不写寄存器。

### T06 有界调度和状态机

- 读取：需求参数、架构状态转换。
- 实现：4 线程/16 队列、单设备 in-flight、重试预算、独立 watchdog、Clock/单调时钟抽象。
- 验证：10 秒边界、首次从未响应、心跳冻结、非法数据、环绕、晚到结果、停用幂等、慢设备隔离。
- 交付：调度与状态服务、确定性单测。
- 验收：每设备最大同时读取数=1；队列满可观察且不会堆积无界任务；watchdog 不等采集返回。

### T07 快照、历史和状态事件持久化

- 读取：数据模型、架构事务和历史策略。
- 实现：每设备短事务；最新快照；首样本+10 秒历史；离散变化事件；提交后视图更新。
- 验证：t=0/1/9/10 的历史保存规则、重复样本键、回滚不更新视图、无数据不填 0。
- 交付：Repository/Service、真实 MySQL 集成测试。
- 验收：快照与应写历史/事件原子提交；通信 I/O 不在事务内；陈旧样本不造趋势点。

### T08 告警去重、确认和恢复

- 读取：需求告警表、架构生命周期、数据模型。
- 实现：LOW_BATTERY、DEVICE_FAULT、DEVICE_OFFLINE；活动槽；确认时间；停用抑制。
- 验证：19/20/24/25 阈值；同一异常重复观测；确认后异常持续；恢复再触发；并发触发；重启后去重。
- 交付：纯规则单测、数据库约束和事务集成测试。
- 验收：每设备每规则至多一条 ACTIVE；低电量/故障不因掉线自动恢复。

### T09 设备和监控 REST API

- 读取：接口设计。
- 实现：登记/查询/名称与启停修改、快照、历史、事件、告警查询与确认；host 允许列表、分页和错误响应；健康检查。
- 验证：400/404/409/503、ID 字符串、UTC、分页排序、时间区间、连接字段不可改、未定义字段拒绝。
- 交付：Controller/DTO/API 测试；健康分组配置。
- 验收：接口契约一致，无任意 host 探测和数据泄漏；readiness 包含数据库。

### T10 SSE 全量实时视图

- 实现：首次快照、每秒全量、15 秒心跳、epoch/sequence、客户端数量/队列上限、断开清理。

- 交付：独立推送执行器、基础流测试。
- 验收：采集线程不负责网络推送；不宣称持久化事件重放。
